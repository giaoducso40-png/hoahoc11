# CHEMVERSE 11

Học liệu tĩnh Hóa học 11 về dẫn xuất halogen, alcohol, phenol, hợp chất carbonyl và carboxylic acid.

## Đưa lên GitHub Pages

1. Giải nén ZIP.
2. Đưa toàn bộ tệp và thư mục ở cấp gốc lên repository GitHub.
3. Vào **Settings → Pages** và chọn **Deploy from a branch**.
4. Chọn nhánh `main`, thư mục `/ (root)`, rồi lưu.

Trang không cần backend hay khóa API. Toàn bộ ảnh, dữ liệu, CSS và JavaScript nằm trong gói. Tiến độ học được lưu bằng `localStorage` trên trình duyệt của từng học sinh.

## Chức năng

- Dashboard cá nhân hóa, XP, độ chính xác và gợi ý bài tiếp theo.
- 5 trạm kiến thức, công thức HTML sắc nét và cảnh báo an toàn.
- Sơ đồ tư duy responsive.
- 3 trò chơi: ghép danh pháp, phân loại, phát hiện sai lệch.
- 25 câu hỏi có giải thích, nhật ký sai và ưu tiên ôn lại.
- Xuất, nhập và đặt lại tiến độ.
- Hoạt động trên máy tính, máy tính bảng, điện thoại; có chế độ giảm chuyển động.

## Lưu ý chuyên môn

Hình 3D chỉ dùng cho mỹ thuật. Công thức, phương trình, điều kiện và danh pháp được dựng bằng HTML để bảo đảm chính xác, có thể sao chép và hỗ trợ trình đọc màn hình.
